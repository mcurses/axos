# 0.26.1: Mark all as read (hub 0.26.1, plugin unchanged)

Effects first: no data migration; no client breaks.

The page's Updates section has a **Mark all as read** button at the top. It marks every unread update in your own
mailbox as read, including those beyond the 50 the list shows. Open questions are not touched: they stay under
"Needs a decision" until you answer them. `POST /ui/api/ack` takes `{"all": true}` for it and returns the number acked.
