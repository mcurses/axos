# 0.26.4: a background program no longer takes a person's main seat (hub 0.26.4, plugin unchanged)

Effects first: one new column (`sessions.hooked_at`), added in place to existing databases; no client breaks.

- **A background program that connects only through the tools no longer takes a person's main seat; one that holds it
  hands it to the person's next Claude Code session.** The main seat goes to the person's first session that reports
  through the plugin's hooks, which every Claude Code session with the plugin does at its start. A program that only
  sends and acks never does. An operator's watchdog program had held a main seat for 11 days, so calls to the project
  reached nobody.
