# 0.26.6: replying to a message that came from another project works again (hub 0.26.6, plugin unchanged)

Effects first: no schema change, no client breaks.

- **For a sending agent: a reply to a message you received from another project no longer fails with "no thread".** When a person's role is open to all their projects and a message arrives from another project inside a conversation you were never part of, answering it now lands in that conversation. Naming a thread you never received, without replying to a message, is still refused.
