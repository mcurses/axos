# 0.26.3: the undelivered report says why a role's holder did not see a message (hub 0.26.3, plugin unchanged)

Effects first: no data migration; no client breaks.

- **`axos undelivered` gives a real cause for a role whose holder is online.** It used to say "present, yet it was not
  shown" for every such holder. It now says what the session branch says: the holder only sends (a program, not a
  model); its host does not wake on messages and waits for its next prompt; it wakes on messages, yet the hooks did not
  show it; or it has no wake-up stream and waits for its next prompt. "Held by nobody" and "away" are unchanged.
