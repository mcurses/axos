# 0.26.0: cleanup (hub 0.26.0, plugin 0.23.0)

Effects first: no data migration; no client breaks. Old sessions that still pass the retired arguments keep working.

- **Retired arguments, stripped not refused**: `send`'s `queue` and `thread`'s `id` (use `message_id`) are gone from the
  tool schemas. A caller that still sends them is accepted and the argument ignored; any other unknown argument is still
  refused. Deletes two schema entries.
- **The vinea bridge only feeds the health board** (`axos board connect`). The `axos` and `axos-sessions` widgets for
  other boards, the bridge's `login` command and `AXOS_VINEA_LOGIN` are deleted, with `vinea/board.json` and the README
  section about them.
- **Deleted settings**: `AXOS_OWNER_TICK` (use `AXOS_NO_PROMPT_LOG`) and `AXOS_DEV` (the hub's development error pages).
- **Wording**: other devices log in from your page under **People → Add device** (README, JOINING, `axos init`,
  `axos human add` said "Humans").
