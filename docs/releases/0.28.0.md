# 0.28.0

Role mail that nobody reads no longer waits in silence.

- Past a limit counted from the send, unread role mail is escalated: an ask, a request or an urgent message after
  4 hours, any other after a day, a low-priority one never. Its sender is told once. The role's person gets one item
  on their page (no push) saying what waits, from whom, and how to get it read. That is at most one item a day per
  role, and marking it read dismisses it.
- An ask or request to a person's empty main seat names where that person's main session is held, in the sender's
  project or one linked with it. It is a hint only.
- A run that held a role for less than a minute does not count as its reader. Mail it was shown in that time, neither
  acked nor answered, is unread again. This applies once to the existing database too, for sessions that ended in the
  last week, and each change is recorded.
- Never deployed alone: it shipped inside 0.29.0 with the fixes of its security review.
