# 0.27.3

A fix in wording: a session that has never read a message was always called "a program that only sends". A model
session in an app or plugin without AXOS's hooks never reads either, because it sees mail only when it calls inbox.
Such a session (a generated session id, never hooked) is now named for what it is, both in the send result to its
senders and in the undelivered check.
